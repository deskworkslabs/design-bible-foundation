# AI Design Bible — Foundation

The free tier of the **AI Design Bible** — a shared, checkable vocabulary
for the design-quality words AI assistants and humans alike throw around
without defining: "polished," "cheap-looking," "cramped," "upscale,"
"modern." Each one gets concrete, visually-checkable tests instead of
vague taste.

Built by [Ethan Hakim](https://ethanhakim.in) — part of a wider catalog
of AI skills and connectors at
[ethanhakim.in/skills](https://ethanhakim.in/skills/). Read more about
the full tiered Design Bible (Foundation free, Professional, Enterprise)
at [ethanhakim.in](https://ethanhakim.in).

## What's here

[`skills/design-bible-foundation/SKILL.md`](skills/design-bible-foundation/SKILL.md)
— the full Foundation skill: five core design qualities, each with
concrete checkable tests and a short review workflow.

## Using it

**With Claude (claude.ai, Claude Code, or the API):** point Claude at the
`SKILL.md` file, or drop it into a project where Claude's skill-loading
is enabled.

**With anything else:** it's plain markdown — read it, adapt it, or
paste the relevant section into your own prompts.

## Beyond Foundation

This file covers the baseline. The paid **Professional** tier expands
each quality into its own deep-dive (typography, spacing/rhythm, color
systems, component anatomy, motion quality) with a reference asset pack
of before/after comparisons. **Enterprise** adds a hosted MCP connector
version so the Bible stays live and current rather than a static file.
Details at [ethanhakim.in](https://ethanhakim.in).
